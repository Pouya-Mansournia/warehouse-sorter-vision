# Contributing

This is a personal project maintained by one person, without a formal review process or CI pipeline.

Issues and pull requests are welcome. Before opening a pull request:

1. Run the test suite: `python -m pytest tests/ -q`
2. Keep changes focused; unrelated formatting or refactors make review harder.
3. If you change detection, tracking, or routing logic, mention how you verified it (which video/config, and the resulting counts).

There is no separate coding style guide. Match the style already used in the file you are editing.
